# Studymate — Cambridge O Level Study App

A mobile-first (460 px max-width) web study app for **Cambridge O Level**, built with vanilla HTML, CSS, and 2D Canvas.

## What's Included
- **3-Level Home Navigation:** `Home (All Subjects)` → `Subject (Respective Chapters & Topics)` → `Topic (7 Sections)`
- **Cambridge O Level Physics (5054):** 6 chapters, 21 dedicated topic pages, 15 interactive 2D Canvas simulations, Paper 1 MCQs, Paper 2 self-marked structured questions, Paper 3/4 virtual practicals, Roman Urdu + Nastaliq Urdu helper, and 35 real-life photos (`images/photo-01.webp`–`photo-35.webp`).
- **Cambridge O Level Mathematics (Syllabus D, 4024):** 9 sections, 16 dedicated topic pages, 4 interactive 2D Canvas Explore tools, Paper 1 quick questions, Paper 2 M1/A1/B1 structured questions, and 16 real-life photos (`images/photo-36.webp`–`photo-51.webp`).
- **7 Outlined O Level Subjects:** Computer Science (2210), Business Studies (7115), English Language (1123), Urdu Second Language (3248), Islamiyat (2058), Pakistan Studies (2059), and Global Perspectives (2069).

## Updating Your GitHub Repository
1. Copy `index.html`, `.nojekyll`, and `README.md` from this folder into the root of your existing GitHub repository (replacing the older `index.html`).
2. Keep your existing `images/` folder (`photo-01.webp` through `photo-51.webp`) in place alongside `index.html`.
3. Commit and push to `main` — GitHub Pages will publish the updated navigation automatically.
